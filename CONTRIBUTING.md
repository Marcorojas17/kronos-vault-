# Cómo contribuir a Kronos-Vault

## Antes de contribuir

Este es un estándar privado, público, autoestablecido y verificable. Las contribuciones son bienvenidas bajo las siguientes reglas.

## Formas de contribuir

1. **Reportar errores** — Abre un issue describiendo el problema.
2. **Sugerir mejoras** — Abre un issue con la propuesta.
3. **Corregir documentación** — Pull request con el cambio.
4. **Traducir** — Abre un issue para coordinar.

## Proceso

1. Fork del repositorio.
2. Crea una rama: `git checkout -b mejora/descripcion-corta`.
3. Haz commits con mensajes claros.
4. Push a tu fork.
5. Abre un Pull Request describiendo el cambio.

## Reglas

- Un cambio por Pull Request.
- Documenta el "por qué", no solo el "qué".
- Respeta el tono y estilo del proyecto.
- No incluyas datos personales ni claves.
- No modifiques el manifiesto ni los principios sin discusión previa.

## Licencia de contribuciones

Al contribuir, aceptas que:
- El código (schemas, tests) se licencia bajo MIT.
- La documentación se licencia bajo CC BY-NC-ND 4.0.
- No reclamarás derechos sobre el estándar.
