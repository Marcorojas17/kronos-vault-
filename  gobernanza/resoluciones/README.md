# Resoluciones

Decisiones formales de la Autoridad de Versiones y del Consejo Génesis.

## Estado actual

Fase Génesis (0.x). Sin resoluciones formales emitidas aún.

## Formato

Cada resolución se publica como `resolucion-YYYYMMDD-NNN.md` con:

- Fecha.
- Tipo (PATCH, MINOR, MAJOR, revocación, etc.).
- Motivo.
- Aprobadores.
- Votos en contra (si los hay).
- Enlaces a discusión.
- Efectos.

## Reglas

1. Toda decisión formal se publica aquí.
2. Sin publicación, la decisión no es válida.
3. Se firma con GPG cuando aplique.
4. Se enlaza desde `../../CHANGELOG.md`.
