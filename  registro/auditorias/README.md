# Auditorías

Registro de auditorías realizadas al estándar Kronos-Vault.

## Estado actual

Sin auditorías formales realizadas. Fase Génesis opera sin auditor externo.

## Tipos de auditoría

| Tipo | Frecuencia | Estado |
|------|------------|--------|
| Interna documental | Semestral | ⏳ Planificada |
| Verificación técnica | Trimestral | ⏳ Planificada |
| Auditoría externa | Cada 2 años | ❌ Pendiente presupuesto |
| Pentest | Anual | ❌ Pendiente presupuesto |

## Formato

Cada auditoría se publica como `auditoria-YYYYMMDD.json` conforme a `../../schemas/auditoria.schema.json`.
