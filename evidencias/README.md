# Evidencias

Registro de pruebas técnicas, auditorías y verificaciones realizadas al estándar.

## Subcarpetas

- `pruebas-integridad/` — Verificaciones de hashes y firmas.
- `pruebas-recuperacion/` — Simulacros de restauración desde respaldos.
- `pruebas-seguridad/` — Detección de uso no autorizado y contramedidas.
- `informes-auditoria/` — Informes de auditorías externas.

## Estado actual

Sin pruebas formales documentadas. Fase Génesis opera con verificación manual.

## Formato

Cada evidencia se publica como `YYYYMMDD-descripcion.md` con:

- Fecha.
- Tipo.
- Procedimiento.
- Resultado.
- Evidencia adjunta.
- Responsable.
