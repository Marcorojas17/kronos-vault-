# Casos Válidos

Sellos que cumplen el schema y pasan todas las verificaciones.

## Casos incluidos

- `sello-valido.json` — Sello del proyecto KRONOS (2607146379465).

## Criterios

Un caso es válido cuando:

1. Cumple el schema.
2. Los hashes coinciden con el archivo original.
3. El sello temporal es verificable.
4. El estado es `activo`.
5. El anclaje blockchain existe.
